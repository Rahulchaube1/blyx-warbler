# Warbler starter

Flag sustained clipping while reporting the energy of an audio frame.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Warbler** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
1
0.5
2
1
```

The vendor directory contains the framework source for 0.1.1 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/warbler) · [View the release](https://github.com/Rahulchaube1/blyx-warbler/releases/tag/v0.1.1)
